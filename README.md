# elaction

Клон аркадной игры **Elevator Action** (Taito, 1983).

## Статус

Проект на старте — пока только каркас репозитория.

## Требования

- Python 3.12+

## Запуск

```bash
python -m venv .venv
source .venv/Scripts/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m elaction
```
