# ADR-0035 · M22b: menu on a live scene, a neon sign, one font

- **Status:** accepted
- **Date:** 2026-09-24
- **Extends:** [ADR-0012](0012-sound-and-interface.md), items 9–11

## Context

After M22 the game looks modern, but the menu remained from M8b: a column of
buttons on an empty gray gradient, pixel Pixellari next to Exo 2 from the HUD,
small labels in the settings and huge dropdown lists, the game title is a line of
text. The user's remark: "the game looks modern, but the menu is shabby".

What the code review showed:

- **There is nothing behind the main menu.** `Main._open_menu` throws away the
  building, and under the `Dim` overlay is an empty screen.
- **The city can already live on its own.** `CityBackdrop` is drawn by its own
  `SubViewport` on layer −1 and takes from the building only the height, width and
  ground from `BuildingRules`; it drives its camera from the current 3D camera.
  Weather, lightning, lights are inside it.
- **The sign on the facade** (`VerticalSign`) needs the building shell built by
  `BuildingShell` and `BuildingRibs` from the layout — it cannot be placed alone.
- **Pixellari lives not only in the menu:** the sign on the facade, floor plaques,
  shaft indicator boards, door plaques.

## Decisions

### 1. Behind the menu — a live scene

The user's decision. The main menu shows the night city (`CityBackdrop`) with its
own ortho camera, tilted like `SideCamera`; the camera slowly drifts along the
street, and the city gives parallax by itself. Weather — rain with lightning or a
clear night, a draw per launch. There is no building facade in the menu: the logo
serves as the sign (decision 2).

On pause and at the end of a game the game itself stays behind the menu — frozen,
blurred and darkened.

### 2. Title — a neon sign

The user's decision. "ELACTION" large, in bold Exo 2, as neon tubes: glow, one
letter blinks — like the building sign. The color is the hotel neon
(`VerticalSign.NEON_HOTEL`), the same as the HUD edge in the first building. Below
it the caption "Elevator Action remake".

### 3. One font — Exo 2

The user's decision. The whole interface and all text in the scene is Exo 2: menu,
the facade sign, floor plaques, shaft indicator boards, door plaques. Pixellari
leaves the project together with its license.

### 4. Layout — a column on the left, plates like the HUD

Menu items are HUD-style plates: dark glass, a neon edge on the left; the selected
item has a brighter edge with a halo. The plate style moves out of `Hud` into a
shared module so the menu and HUD do not drift apart. Dropdown lists are replaced
by a "‹ value ›" switcher: left-right cycles through values, on a gamepad it is
one press rather than an open list. The high-score table is a grid: with a
proportional font, columns made of spaces drift apart.

### 5. Animation and sound

The user's decision. Pages change smoothly, the selected item is highlighted with
an animation. Hover, select and back sounds are synthesized, like the others
(`tools/render_audio.py`); in M23 they are replaced along with all the sound.

## Not in the milestone

- **Key rebinding** — as before, after release (ADR-0012, item 10).
- **A building facade behind the menu:** the sign on the facade needs the building
  shell.

## Consequences

- The menu is the first thing the player sees, and now it speaks the same
  language as the game.
- Text in the scene changes font: floor plaques had the digit height tuned for
  Pixellari — it has to be recomputed.
- One font license remains in the release archive.
